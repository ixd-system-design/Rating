Rating Scale Input

Custom Radio Buttons with SVG and CSS

Thirsty?
Rating is 1

This page uses standard radio buttons to implement a user interface for rating on a scale of one to five. Poké Balls take the place of the more conventional stars.

Each radio button label uses the same external Poké Ball SVG. Active ratings show its original colors, while inactive ratings use a CSS grayscale filter and reduced opacity.

Ratings appear in descending order (5-4-3-2-1) in HTML, but this arrangement is flipped in CSS via flex-direction: row-reverse. This approach makes it possible to exploit Subsequent Sibling (~) logic in CSS. The :checked and :hover pseudo-classes determine which images appear active. Hovering previews a rating without changing the selection.

As a caviat, keep in mind that this sort of adaptation involves tradeoffs between visual appearance, brand, usability, and accessibility.

For comparison (and further inspiration) note that it's also possible to do this without SVGs. For example, this codepen by James Barnett employs Font Awesome icons and the ::before pseudo-element. Remember that there are many ways to solve a problem. What other CSS or JavaScript-based approaches can you find?
